# Desafio Aiko

Este projeto é parte de um desafio técnico, utilizando tecnologias modernas do ecossistema JavaScript/TypeScript para construir uma aplicação web interativa e responsiva.

## 🚀 Tecnologias utilizadas

### 🧱 Base do Projeto
- **Vite**: Ferramenta de build extremamente rápida para aplicações front-end modernas.
- **TypeScript**: Superset do JavaScript que adiciona tipagem estática, aumentando a confiabilidade e produtividade do desenvolvimento.

### ⚛️ Interface e Componentes
- **React**: Biblioteca para construção de interfaces declarativas e reativas.
- **Chakra UI**: Biblioteca de componentes acessíveis e altamente personalizáveis para construção de interfaces modernas com rapidez.
- **React Icons**: Conjunto de ícones populares integrados facilmente com React.

### 🎨 Estilização
- **@emotion/react**: Biblioteca de CSS-in-JS usada pelo Chakra UI para estilização de componentes.

### 🗺️ Mapas Interativos
- **Leaflet**: Biblioteca open-source para mapas interativos.
- **React Leaflet**: Integração do Leaflet com React para criar mapas interativos usando componentes declarativos.

### 🧹 Qualidade de Código
- **ESLint**: Ferramenta de linting para manter o código limpo e padronizado.
- **eslint-plugin-react-hooks / react-refresh**: Plugins para garantir boas práticas com hooks e suporte ao Fast Refresh no desenvolvimento.

## 📦 Scripts disponíveis

- `dev`: Inicia o servidor de desenvolvimento.
- `build`: Compila o TypeScript e gera os arquivos de build.
- `lint`: Executa o ESLint para verificação de boas práticas e problemas no código.
- `preview`: Inicia uma prévia do build de produção localmente.
