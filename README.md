# ✅ Desafio Técnico

## 📦 Sobre o Projeto

Este repositório contém a minha solução para o desafio técnico proposto. A implementação foi realizada com foco em código limpo, funcional e modular, buscando atender os requisitos básicos e implementar os extras propostos.

## 🚧 Dificuldades Encontradas

Durante o desenvolvimento, alguns pontos se destacaram como desafios:

- **Uso de IA**: Parte significativa do projeto foi desenvolvida com auxílio de inteligência artificial (IA), o que facilitou bastante algumas etapas, mas também trouxe o desafio de conciliar trechos de código gerados separadamente, garantindo que funcionassem em conjunto de forma estável.

- **Requisitos Extras**: A implementação da parte básica do desafio foi relativamente tranquila. Porém, ao avançar para os requisitos extras, surgiram inconsistências e conflitos entre as soluções propostas pela IA, exigindo depuração cuidadosa e ajustes manuais para que tudo funcionasse corretamente.

- **Integração e Testes**: Garantir que todos os recursos extras funcionassem de forma coesa e sem gerar erros exigiu atenção especial, especialmente em testes manuais e refatorações pontuais.

Apesar desses obstáculos, finalizei uma versão que contempla quase todos os extras de forma funcional e sólida.

## 🛠️ Tecnologias e Abordagens Utilizadas

- **React.js com Vite**
- **Typescript**
- **Leaflet.js** (mapa interativo)
- **TailwindCSS** (estilização)
- **React Modal** para exibição de histórico detalhado
- **Day.js** para manipulação de datas
- **Auxílio de IA** para acelerar etapas de codificação e busca de soluções
- **Estrutura modular** para facilitar leitura e manutenção do código
- Boas práticas como separação de responsabilidades, uso de componentes reutilizáveis, tratamento de erros e organização de arquivos
