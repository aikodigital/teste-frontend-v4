# 🏆 Teste Frontend

![FlorestaTech](./src/assets/imagens/logo-florestatech.png)

FlorestaTech é uma empresa de equipamentos florestais e esta aplicação consiste na gestão e rastreio desses equipamentos, através desse sistema é possível verificar as posições e estados dos equipamentos da empresa, e também gerar arquivos PDF para análises e relatórios.

## 📦 Tecnologias utilizadas

- [Angular](https://angular.io/)
- [Bootstrap](https://getbootstrap.com/)
- [ngx-bootstrap](https://valor-software.com/ngx-bootstrap/)
- [Leaflet](https://leafletjs.com/) - Mapa interativo
- [jsPDF](https://github.com/parallax/jsPDF) e [jsPDF-AutoTable](https://github.com/simonbengtsson/jsPDF-AutoTable) - Geração de PDF
- [RxJS](https://rxjs.dev/)

## 🚀 Como executar o projeto

### ✅ Requesitos

- Node.js - Baixar: (https://nodejs.org).
- Angular Cli - Comando para instalar (npm install -g @angular/cli).
- Git

Para conseguir executar o projeto localmente siga estes passos.

1 - Executar no terminal 'bash' do git - "https://github.com/Terchaki/teste-frontend-v4.git".

2 - Executar o comando "npm install" para instalar as dependências do projeto.

3 - Executar o comando "ng serve" para abrir a aplicação em "http://localhost:4200".

## 🛠 Funcionalidades principais da aplicação

- Visualização dos equipamento na posição e estado mais recente.
- Visualização de trajeto percorrido no mapa pelo equipamento.
- Geração de arquivo PDF do histórico de posições.
- Responsividade para dispositivos móveis.
